# Measure Size

Right-click a file or folder in the Explorer and pick **Measure Size** to see how big it is.

- Folders are added up recursively, with a file and folder count.
- Works on a multi-selection: the total of everything selected is shown.
- Large folders show a progress notification that can be cancelled.
- **Copy** on the result puts the text on the clipboard.

Sizes are the sum of file sizes in decimal units (1 MB = 1,000,000 bytes), the same as Finder's first number. Symlinks are not followed.
